# ESTIM APP 🎓

**ESTIM App** est l'application mobile officielle de l'**Ecole Supérieure de Technologie d'Ingénierie et de Management (ESTIM)**, basée à Brazzaville, République du Congo.

Ce projet vise à transformer l'expérience académique des étudiants en centralisant les outils numériques essentiels et en fluidifiant la communication entre l'administration et les apprenants.

## 🚀 Objectifs du Projet

L'application a été conçue pour répondre à deux enjeux majeurs :

1.  **Améliorer le quotidien des étudiants** : Accès rapide aux informations critiques (emplois du temps, notes, ressources).
2.  **Faciliter la communication** : Créer un canal direct et fiable pour les annonces administratives et les notifications urgentes.

## ✨ Fonctionnalités Clés

  * **Gestion d'Emploi du Temps** : Consultation en temps réel des horaires de cours et des changements de salles.
  * **Annonces & Notifications** : Flux d'actualités pour ne manquer aucune information officielle de l'administration.
  * **Espace Étudiant** : Accès simplifié aux ressources pédagogiques et aux informations de scolarité.
  * **Interface Minimaliste** : Design épuré axé sur l'efficacité et la rapidité d'exécution (Utility-First).

## 🛠️ Stack Technique

L'application repose sur des technologies modernes pour garantir performance et scalabilité :

  * **Frontend Mobile** : React Native / Expo (ou ta techno spécifique)
  * **Backend** : HonoJS / Node.js
  * **Base de données** : PostgreSQL avec Prisma ORM
  * **UI/UX** : Design minimaliste et optimisé

## 📦 Installation & Développement

Pour cloner le projet et lancer l'environnement de développement :

```bash
# Cloner le dépôt
git clone https://github.com/Ebana27/estim-app.git

# Accéder au dossier
cd estim-app

# Installer les dépendances
npm install

# Lancer l'application
npm run dev
```

## 📍 Contexte Régional

Ce projet est spécifiquement développé pour le contexte éducatif de la **République du Congo**, avec une optimisation pour une utilisation fluide même sur des réseaux mobiles variables.
