# glossary.md - Dictionnaire technique (React, Ionic, Hono)

> Version JS (pas TypeScript).

---

## A

- API: Interface pour communiquer entre front et backend.
- Async/Await: Syntaxe pour travailler avec des promesses.
- Axios: Librairie HTTP alternative a fetch.

## B

- Backend: Serveur qui gere la logique et la base de donnees.
- Base de donnees: Stockage persistant des donnees.
- Babel: Outil qui transpile le code JS/JSX.
- Bundler: Outil qui construit lapp (Vite).

## C

- CORS: Regles qui bloquent ou autorisent les requetes cross-origin.
- CRUD: Create, Read, Update, Delete.
- Component: Bloc UI reutilisable en React.
- Context: Systeme React pour partager un state global.

## D

- Dependency: Une librairie installee via npm.
- DOM: Document Object Model, representation de la page.
- Dev server: Serveur local de dev (Vite).

## E

- Endpoint: URL API specifique.
- Error boundary: Composant React qui capture les erreurs UI.

## F

- Fallback: Solution de secours si une action echoue.
- Fetch: API JS pour faire des requetes HTTP.
- Frontend: Interface utilisateur.

## G

- Global state: Etat partage partout.
- Git: Outil de versioning.

## H

- HMR: Hot Module Replacement (mise a jour sans reload).
- Hono: Framework backend JS rapide.
- Hook: Fonction React qui ajoute des features (useState).

## I

- Ionic: Framework UI mobile-first.
- IonPage: Composant Ionic obligatoire par page.

## J

- JSX: Syntaxe proche HTML dans React.

## L

- Library: Ensemble de fonctions reutilisables.
- Lifecycle: Etapes de vie dun composant (mount, update, unmount).

## M

- Migration: Changement de schema base de donnees.
- Middleware: Fonction intermediaire dans le backend.
- Mock: Donnees fictives pour tester.
- Model: Representation de donnees (ex: Prisma schema).

## N

- Node.js: Runtime JS pour backend.
- NPM: Gestionnaire de packages.

## O

- ORM: Outil pour manipuler la DB (Prisma).

## P

- Payload: Donnees envoyees dans une requete (body JSON).
- Props: Parametres passes a un composant React.
- Promise: Objet representant une operation async.
- Prisma: ORM moderne pour Node.

## R

- React: Librairie UI basee sur composants.
- Route: Chemin URL vers une page.
- Router: Outil pour naviguer entre pages.
- REST: Style dAPI classique.

## S

- State: Donnees qui changent dans le composant.
- Schema: Definition de structure de donnees.
- Service: Fichier qui gere les appels API.
- SPA: Single Page Application.
- SQL: Langage base de donnees.

## T

- Tab: Onglet (Ionic Tabs).
- Token: Cle de securite.
- Transpile: Convertir un code en un autre format.

## U

- UI: Interface utilisateur.
- URL: Adresse web.
- useEffect: Hook React pour effets.
- useState: Hook React pour etat.

## V

- Vite: Bundler moderne rapide.
- Validation: Controle des donnees (Zod).

## W

- Worker: Processus leger.

---
